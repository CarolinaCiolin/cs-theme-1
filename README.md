# CS Theme 1

Tema WordPress reutilizável de Carolina Ciolin. Projeto piloto: Christoph Wimmersberger.

## Componentes

- `themes/cs-theme-1/` — tema-base clássico/híbrido.
- `themes/cs-theme-1-christoph/` — tema-filho do site piloto.
- `plugins/cs-blocks/` — plugin de blocos Gutenberg reutilizáveis.

## Stack e objetivos

WordPress, Gutenberg, PHP, CSS, JavaScript. Compatibilidade planejada com Elementor Free, Rank Math, LiteSpeed Cache, UpdraftPlus, Real Cookie Banner e Calendly.

## Organização do código

O código-fonte dos três componentes será enviado a este repositório a partir do pacote de trabalho da Fase 1. **Este README inicial não representa o código completo instalado.**

Os ZIPs de instalação são artefatos gerados e não devem substituir as pastas de código-fonte.

## Desenvolvimento

Use VS Code + Codex no Windows. As páginas serão testadas no WordPress e os lançamentos serão feitos como ZIPs versionados.

### Fase 1

Estrutura técnica dos três componentes criada. Próximos passos: incorporar o código-fonte ao GitHub, validar e começar a homepage de acordo com a especificação aprovada.
